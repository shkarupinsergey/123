# Множество Мандельброта
# Данный проект представляет собой графическое приложение для визуализации и исследования множества Мандельброта, реализованное на Python с использованием стандартной библиотеки tkinter.
# Особенности реализации
# Отрисовка фрактала: Приложение вычисляет и отображает множество на холсте размером 540x400 пикселей. Цветовая палитра строится на оттенках красного цвета.
# Управление масштабом: С помощью ползунка «Увеличение» можно масштабировать изображение в диапазоне от 1 до 30.
# Настройка детализации: Ползунок «Число итераций» позволяет изменять глубину расчета от 5 до 150 итераций, что влияет на точность отрисовки границ фрактала.
# Навигация: Позиционирование осуществляется кликом мыши по изображению — выбранная точка становится новым центром экрана.
# Быстрый сброс: Кнопка «Сбросить» возвращает все параметры к настройкам по умолчанию (центр на координатах x=-0.6, y=0.0, масштаб 1, 70 итераций).
# Оптимизация вычислений: В алгоритм встроена проверка принадлежности точек к главным областям множества (кардиоиде и главному кругу), что позволяет пропускать долгие циклы и ускоряет процесс отрисовки.
# Плавная перерисовка: Используется механизм задержки перед обновлением изображения (after_cancel и after), чтобы избежать зависаний интерфейса при быстром перемещении ползунков.
